# Harbor for Linux

> [!WARNING]
> This is a prototype shell, not a usable Harbor client or supported Linux release.

The Tauri project currently contains platform setup and starter commands. It does not yet implement Harbor's repository dashboard, authentication flow, provider integrations, or release-quality packaging.

## Contributor setup

Use this directory only for exploratory platform work. Before claiming Linux support, implement the user-visible Harbor workflow, add automated tests, validate secure credential storage, and verify packages on supported distributions.

See [the repository platform matrix](../docs/platforms.md) for the release gates.
